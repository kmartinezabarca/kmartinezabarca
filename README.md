### 🤖 Tratamientos asistidos por IA

ROKE Pet incorpora un sistema para digitalizar tratamientos veterinarios.

El usuario puede fotografiar una receta y el sistema utiliza IA para identificar información como:

```text
Veterinary Prescription
        │
        ▼
   Image Analysis
        │
        ▼
 ┌───────────────────┐
 │ Medication        │
 │ Dose              │
 │ Frequency         │
 │ Duration          │
 │ Instructions      │
 └───────────────────┘
        │
        ▼
 User Verification
        │
        ▼
Treatment Schedule
        │
        ▼
 Notifications
        │
        ▼
 Medical History
```

Los recordatorios **no se activan automáticamente**: el usuario revisa la información detectada y decide cuáles desea habilitar.

## 🛟 ROKE Pet Rescue

**ROKE Pet Rescue** es un módulo diseñado para conectar rescatistas, comunidad, veterinarios, refugios, voluntarios y donadores.

Su principal objetivo es la **transparencia y trazabilidad de los rescates**.

Incluye conceptos como:

* Casos de rescate
* Evidencia fotográfica y video
* Ubicación
* Donaciones
* Gastos comprobables
* Facturas
* Diagnósticos veterinarios
* Tratamientos
* Cronología del rescate
* Voluntariado
* Hogares temporales
* Refugios
* Adopciones
* Moderación
* Auditoría
* Prevención de fraude

La intención es que un rescate pueda documentarse desde que se encuentra al animal hasta su recuperación y eventual adopción.
