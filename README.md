## 👨‍💻 Sobre mí

Soy ingeniero de sistemas y fundador de **ROKE Industries**, una empresa tecnológica mexicana donde diseño y construyo productos que combinan **software, infraestructura, automatización, cloud, inteligencia artificial, electrónica y fabricación digital**.

Me interesa especialmente construir sistemas de extremo a extremo.

No solamente desarrollar una aplicación, sino entender y construir la arquitectura completa detrás de ella:

**Producto → Frontend → Backend → APIs → Bases de datos → CI/CD → Containers → Infraestructura → Redes → Hardware → Monitoreo → Operación**

Trabajo principalmente con arquitecturas SaaS, aplicaciones web y móviles, infraestructura Linux, DevOps y sistemas embebidos.

También diseño y construyo proyectos físicos relacionados con electrónica, CNC, IoT, automatización y fabricación digital.

## 🚀 Actualmente

### 🏢 ROKE Industries

Actualmente estoy construyendo y escalando **ROKE Industries**, un ecosistema tecnológico que combina productos SaaS, infraestructura cloud y hardware.

Entre los productos en los que trabajo se encuentran:

### 🐾 ROKE Pet

Plataforma para la gestión integral de mascotas.

Incluye:

* Expediente médico digital
* Historial de vacunas
* Tratamientos
* Recordatorios
* Identificación QR y NFC
* Modo mascota perdida
* Portal veterinario
* Gestión de cuidadores
* Adopciones
* ROKE Pet Rescue

También estamos desarrollando funcionalidades de IA para interpretar recetas veterinarias, extraer tratamientos y permitir al usuario generar recordatorios de medicamentos y dosis a partir de la información detectada.

### 🛟 ROKE Pet Rescue

Ecosistema para rescate y recuperación de animales enfocado en transparencia y seguimiento.

Estamos diseñando herramientas para:

* Casos de rescate

* Seguimiento veterinario
* Tratamientos
* Hogares temporales
* Voluntarios
* Refugios
* Adopciones
* Cronología completa del rescate
* Prevención de fraude
